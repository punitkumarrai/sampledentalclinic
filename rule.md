# rule.md

## Project Name
Sample Dental Clinic

## Purpose
Build a **small, premium, modern, fast dental clinic website** for a fictional clinic called **Sample Dental Clinic**.

This website must help the clinic:
1. build trust fast
2. generate appointment bookings
3. generate phone and WhatsApp leads
4. feel premium but local
5. look modern without looking flashy
6. work beautifully on mobile, tablet, laptop, and desktop

---

## Source of Truth
This file is the permanent design and build direction for the project.

When generating, editing, or refining this project:
- always follow this file first
- do not drift from these goals
- do not introduce random design styles
- do not replace the core brand direction unless explicitly instructed
- prefer **small targeted updates** over full regeneration
- preserve working structure and improve weak parts incrementally

---

## Core Brand Direction
The website should feel:

- premium
- modern
- clean
- calm
- family-friendly
- medically trustworthy
- locally credible
- polished
- easy to use
- mobile-first

It must **not** feel:

- outdated
- generic medical template
- SaaS dashboard
- fashion/editorial luxury site
- noisy
- gimmicky
- childish
- cartoonish
- over-animated
- cold corporate

### Correct brand formula
**Premium local dental clinic**

Not luxury-for-show.  
Not low-cost generic clinic.  
Not startup website.  
Not over-designed AI demo.

---

## Website Scope
This is a **small business website**, not a huge website.

### Required Pages
- Home
- About
- Services
- Contact
- Book Now

No unnecessary extra pages unless explicitly requested.

---

## Technical Stack
Use:

- **Next.js App Router**
- **TypeScript**
- **Tailwind CSS**

### Technical Priorities
- fast loading
- SEO-friendly
- semantic HTML
- mobile-first
- optimized images
- lightweight code
- reusable components
- accessible navigation
- clean forms
- production-quality structure
- minimal JavaScript where possible

### Rendering Preference
- prefer static rendering where possible
- keep pages lightweight
- do not add heavy dependencies unless necessary
- do not use bloated animation libraries unless clearly needed

---

## Performance Rules
The site must be fast.

### Must do
- optimize image usage
- avoid oversized images
- avoid autoplay heavy videos
- avoid unnecessary scripts
- avoid complex visual effects that hurt speed
- keep layout simple and efficient
- prioritize Core Web Vitals

### Must not do
- no video-heavy hero backgrounds
- no unnecessary third-party scripts
- no bloated component libraries unless required
- no heavy parallax effects
- no animation for the sake of animation

---

The website must be SEO-friendly.

### Must include

- meta descriptions
- clean URL structure
- proper internal linking
- crawlable content
- readable copy
- location-based references where appropriate
- local business relevance
- optimized image alt text
- structured, scannable page sections

## Design System

### Visual Feel
The website should feel:
- premium through restraint
- modern through spacing and typography
- trustworthy through clarity and realism
- local through grounded copy and practical contact options

### Color Palette
Use:
- soft white / off-white backgrounds
- deep navy contrast sections
- teal / blue-green accents
- dark charcoal text
- optional subtle warm neutral touch only if needed

### Avoid
- loud gradients
- neon colors
- too many accent colors
- cheap “medical blue” template styling
- muddy brown-heavy palette
- grayscale-only luxury styling

---

## Typography Rules
Typography should feel:
- modern
- premium
- readable
- strong on mobile
- calm
- clear

### Preferred style
- clean modern sans-serif for body
- refined modern headings
- high contrast and strong readability
- avoid ultra-thin fonts
- avoid decorative fonts
- avoid outdated clinic typography

---

## Layout Rules
Use a clean multi-section layout with strong spacing and section rhythm.

### Must include
- generous whitespace
- modern card styling where needed
- soft rounded corners
- subtle shadows
- clear hierarchy
- premium section flow
- readable content blocks

### Must avoid
- cluttered pages
- cramped mobile layouts
- too many small cards
- too many icons
- too many equal-weight elements fighting for attention

---

## Header Rules
The header must be sticky.

### Requirements
- sticky on scroll
- visually refined
- slight visual change on scroll is allowed
- can shrink slightly or gain subtle blur/shadow
- should feel cool and modern when scrolling
- should not become bulky
- should not make the website boring

### Header content
- brand name / logo: Sample Dental Clinic
- nav links:
  - Home
  - About
  - Services
  - Contact
- primary CTA:
  - Book Appointment

### Must not include
- no phone number in header
- no overloaded top utility bar unless explicitly requested

---

## Hero Rules
The hero is one of the most important sections.

### Goal
Make users quickly feel:
- this clinic is clean
- this clinic is trustworthy
- this clinic is modern
- this clinic feels calm and premium
- booking is easy
- calling is easy
- the clinic cares about comfort

### Hero content
Must include:
- strong headline
- short reassuring subheadline
- primary CTA: Book Appointment
- secondary CTA: Call Now
- one premium hero image

### Hero image style
Use:
- dentist with patient consultation
- warm and trustworthy
- clean dental setting
- modern and realistic
- human-centered
- premium but approachable

### Avoid
- cheesy smiling stock photo energy
- fake CGI treatment room as the only trust signal
- hyper-artificial AI faces
- overly dramatic image composition

## Mobile-First Rules
The site must be designed mobile-first.

### Must do
- readable hero on small screens
- clean stacked layout
- strong tap targets
- proper spacing
- no cramped cards
- no tiny text
- fast interactions
- sticky header that behaves well on mobile

### Must not do
- desktop-first layout squeezed into mobile
- oversized hero image dominating the screen
- weak CTA visibility
- cluttered footer/contact layout

---

## Anti-Drift Rules
When making future edits:
- do not redesign the entire site unless explicitly asked
- preserve the existing structure when possible
- improve only the requested section(s)
- keep color palette consistent
- keep typography consistent
- keep imagery style consistent
- do not introduce new random themes
- do not add new features unless requested
- do not change the brand tone

### Important edit policy
When updating anything:
- prefer targeted edits
- preserve 80–90% of existing working structure
- only touch related components
- avoid full regeneration
- avoid unnecessary rewrites
- avoid token-heavy redesigns

---

## Decision Priority Order
When in doubt, prioritize in this order:

1. Trust
2. Clarity
3. Speed
4. Mobile usability
5. Conversion
6. Visual polish
7. Animation

Do not sacrifice trust or speed for decoration.
